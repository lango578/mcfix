# 邮件通知配置指南

> 这份文档讲三件事：**玩家回执**怎么开、**管理员提醒**怎么开、
> 以及最关键的 —— **为什么 VPS 上必须用 SMTP 而不是装 Postfix**。
>
> English: [`EMAIL-NOTIFICATIONS.en.md`](EMAIL-NOTIFICATIONS.en.md)

---

## 一、这套邮件是干什么的

后台「系统设置 → 邮件通知」里勾一个开关、填一个邮箱，就全自动了：

| 发给谁 | 什么时候 | 内容 |
|---|---|---|
| **玩家** | 提交反馈后立刻 | 「已经收到你的反馈，正在检测」+ 工单链接 |
| **玩家** | 修好 / 转人工 / 驳回时 | 结果 + 体检明细 + **他自己需要做的事** |
| **你自己** | 每收到一条新反馈 | 服务器、玩家、分类、玩家原话、后台工单直达链接 |

玩家那两封需要他在反馈页填了邮箱（选填，不填也能正常提交）。

**工单结束后系统会把玩家邮箱抹成掩码**（`ab***@qq.com`），
邮件队列里的明文地址在发出去之后也会立刻清空 —— 不会长期留存玩家隐私。

> 这个邮件模块和「通知设置」里的**通知渠道**是两回事：
> 通知渠道（钉钉 / 企微 / 飞书 / Telegram…）是事件推送，给管理员和群看的；
> 这里只管邮件，而且玩家回执只有这里有。

## 二、为什么必须用 SMTP（重点）

很多人第一反应是"装个 Postfix 就行"。**在 VPS 上这条路走不通。**

PHP 自带的 `mail()` 做的事是"把信交给本机邮件服务，让它**直连收件方的 25 端口**投递"。
而**绝大多数 VPS 服务商把出网 25 端口封了**（防垃圾邮件）。实测一台普通香港 VPS：

```
连 mx3.qq.com:25          → 连不上
连 mx1.qq.com:25          → 连不上
连 Gmail 的收信服务器:25   → 连不上
连 smtp.qq.com:465        → 通
连 smtp.qq.com:587        → 通
```

**所以装了 Postfix 也没用** —— 它只会把邮件堆在队列里，界面上看着"装好了"，
实际一封都发不出去。

就算 25 端口侥幸通，VPS 的 IP 没有 SPF / DKIM / 反向解析，
QQ、163 也基本会判垃圾邮件或者直接拒收。

**正确做法**：填一个真实邮箱账号 + 它的授权码。系统登录 `smtp.qq.com`
这类服务器，由服务商帮你转发 —— 送达率、SPF、DKIM 全都是现成的。

> 家里 / 公司自建、25 端口没被封的环境仍然可以用 `mail()` + Postfix，
> 那条通路保留了：不勾「用 SMTP 发信」就自动回退。

## 三、怎么配（3 步）

### 第 1 步：去邮箱里拿授权码

以 QQ 邮箱为例：

1. 电脑浏览器打开 **mail.qq.com** 并登录
2. 点顶部 **设置** → **账户**
3. 往下找到 **「IMAP/SMTP服务」**，点 **开启**
4. 按提示用手机发一条短信
5. 得到一串 **16 位字母**的授权码 —— **复制下来**

> ⚠️ **授权码不是你的 QQ 密码**，而且只显示一次，关掉页面就看不到了。

各家的对照：

| 邮箱 | 去哪拿 | 拿到的是什么 |
|---|---|---|
| QQ 邮箱 | 设置 → 账户 → 开启 IMAP/SMTP | 16 位授权码 |
| 163 / 126 | 设置 → POP3/SMTP/IMAP | 授权码 |
| QQ 企业邮 | 不用拿 | 邮箱登录密码 |
| Gmail | Google 账号 → 安全性 → 应用专用密码 | 16 位应用密码 |
| 阿里云邮 | 不用拿 | 邮箱登录密码 |

### 第 2 步：在后台填进去

后台 →【系统设置】→「**邮件通知**」→「**发送方式**」：

| 字段 | QQ 邮箱 | 163 | Gmail |
|---|---|---|---|
| ✅ 用 SMTP 发信 | 勾上 | 勾上 | 勾上 |
| SMTP 服务器 | `smtp.qq.com` | `smtp.163.com` | `smtp.gmail.com` |
| 端口 | `465` | `465` | `587` |
| 加密方式 | SSL（465） | SSL（465） | STARTTLS（587） |
| 邮箱账号 | 你的 QQ 邮箱 | 你的 163 邮箱 | 你的 Gmail |
| 密码 / 授权码 | **第 1 步的 16 位授权码** | 授权码 | 应用专用密码 |

再往下「**收件人与开关**」里：

- **管理员邮箱** —— 你自己收提醒的地址（可以和上面同一个）
- 勾上「玩家提交新工单时给管理员发一封」
- 勾上「给玩家发『已收到』和『处理结果』」
- 勾上「工单结束后把玩家邮箱换成掩码」（**建议保持开启**）

**保存。**

### 第 3 步：点「测试邮件」验证

右侧栏卡片里填一个收件邮箱 → 点「立刻发一封」。
**没收到先翻垃圾邮件箱。**

失败时它会告诉你服务器原话，对照下表：

| 提示 | 什么意思 |
|---|---|
| `535` + "要填授权码" | 密码那栏填成登录密码了，改成授权码 |
| `550` + "收件人被拒绝" | 收件地址打错了 |
| 「连不上 host:port」 | 服务器地址或端口填错了，或者服务商封了这个端口 |
| 「服务器不支持 STARTTLS」 | 端口和加密方式对不上：465 配 SSL、587 配 STARTTLS |
| 「mail() 返回失败」 | 没配 SMTP，系统回退到了 `mail()` —— 去把 SMTP 填上 |

## 四、别忘了计划任务

邮件是**异步**发的：提交时只入队，真正发送交给 cron 每分钟发一批，
失败按 1/3/10/30 分钟退避重试，最多 5 次。

**没配计划任务的话邮件会一直堆在队列里。**

宝塔【计划任务 → Shell 脚本】，每分钟：

```bash
cd /www/wwwroot/mcfix && /www/server/php/83/bin/php bin/mcfix.php cron
```

> ⚠️ **必须用 `bin/php`，不是 `php-fpm`。** 先在 SSH 里 `which php` 确认路径。
> 填成 `php-fpm` 的话脚本根本不会执行，而且不会有任何报错。

后台「邮件通知」卡片上能看到队列状态（待发 / 已发 / 失败），
也可以点「催发邮件队列」立刻发一批，不用等 cron。

## 五、进阶：用 `config.php` 配

后台能配的，`config.php` 里也都能写：

```php
'email' => [
    'enabled'       => true,
    'admin_to'      => 'you@example.com',   // 收新工单提醒
    'from_name'     => 'MC 故障反馈系统',
    'notify_player' => true,
    'notify_admin'  => true,
    'purge_email'   => true,                // 工单结束后抹掉玩家邮箱

    'smtp' => [
        'enabled'    => true,
        'host'       => 'smtp.qq.com',
        'port'       => 465,
        'encryption' => 'ssl',              // ssl(465) | tls(587) | none
        'username'   => 'youremail@qq.com',
        'password'   => '你的16位授权码',
        // QQ / 163 要求发件地址 == 登录账号，默认自动对齐，不用管
        'force_from_username' => true,
    ],
],
```

**发件地址会自动对齐到登录账号** —— QQ、163 会检查这个，不一致直接 550 拒收。
这个坑很隐蔽，所以默认帮你处理了（连正文里的 `From:` 头一起改）。

## 六、常见问题

**Q：能用 `no-reply@我的域名` 当发件人吗？**

QQ、163 会检查「发件地址 == 登录账号」，不一致直接 550。
真想用自己域名发信，得申请企业邮箱，或用阿里云邮 / 腾讯企业邮这类支持自有域名的服务。

**Q：能用 SendGrid / Mailgun / 阿里云 DirectMail 吗？**

可以。任何提供 SMTP 的服务都行，把服务器地址、端口、用户名、密码填进去即可。
这类服务的送达率通常比个人邮箱还好，适合玩家量大的服。

**Q：我不在 VPS 上，是家里/公司自己的机器，25 端口没被封**

那可以走 `mail()` + Postfix：不勾「用 SMTP 发信」就自动回退。
但一般来说装个 SMTP 仍然更省事、送达率也更好。

**Q：玩家不填邮箱会怎样？**

不影响提交，只是收不到那两封邮件。玩家页面上写明了这一点。

**Q：玩家邮箱会被存多久？**

只为了发那两封邮件。发出去之后，队列里的明文地址立刻清空；
工单结束（修好 / 转人工 / 驳回 / 关闭）时，数据库里也只留掩码 `ab***@qq.com`。
自由文本的「联系方式」里如果写了邮箱，同样会被抹掉。

**Q：能不能只给管理员发，不给玩家发？**

可以，把「给玩家发」那个勾去掉就行。

**Q：完全不想要邮件？**

把「启用邮件」的勾去掉，一封都不发，工单流程不受影响。
